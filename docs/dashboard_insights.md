# Dashboard Insights

## Current technology usage

JavaScript is the largest category in the displayed top 10 programming languages, followed by HTML/CSS and SQL.

For databases, MySQL is the largest displayed category, followed by Microsoft SQL Server and PostgreSQL.

## Future technology trend

JavaScript remains the leading displayed future language. HTML/CSS, Python, and SQL also show strong future interest.

For databases, PostgreSQL has the largest displayed future preference, followed by MongoDB and MySQL.

## Demographics

The dashboard shows a heavily male respondent population at 93.6%, with women representing 6.4%.

The largest displayed age group is 25 to <33, followed by respondents under 25 and those aged 33 to <41.

## Interpretation

The current-versus-future views provide a useful way to distinguish technologies that are already widely used from technologies respondents are interested in developing further.

The dashboard is descriptive. It does not establish why respondents prefer particular technologies or whether those preferences translate into employment outcomes.
